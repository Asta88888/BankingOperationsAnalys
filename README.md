# Приложение для анализа банковских операций.
## Описание
Данный проект использует информацию из Excel-файла, анализирует данные и предоставляет информацию по курсу валют, стоимости акций, топ 5 транзакций по сумме платежа, выдает общую информацию по картам(последние 4 цифры карты; общая сумма расходов; кешбэк (1 рубль на каждые 100 рублей), траты по заданной категории за последние три месяца от указанной даты), а также распознаёт в какое время пользователь совершил вход и здоровается исходя из времени суток.

## Установка и использование.
Для использования данного проекта, вам необходимо:
* клонировать репозиторий: https://github.com/Asta88888/BankingOperationsAnalys
* заменить ключи API в .env.example и .env.example заменить на .env
* установить зависимости poetry: __poetry install__

## Тестирование
Для тестирования проекта используйте команду: __pytest --cov-report term-missing --cov__

## Документация и ссылки
В проекте использованы сторонние сервисы для запроса текущего курса валют и стоимости акций из S&P500:
1) https://apilayer.com/
2) https://twelvedata.com/pricing

Для использования данных сервисов, вам необходимо пройти регистрацию и получить API KEY, а далее личным ключом заменить текущий.
